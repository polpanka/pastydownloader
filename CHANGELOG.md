# Changelog

All notable changes to PastyDownloader.

## 1.7 — 2026-09

- Minor bug fixes and About screen tidy-up.

## 1.5 — 2026-08

- Android build added: same PySide6 codebase, real on-device downloads and audio+video merging.
- Embedded subtitles, optional browser cookies for login-gated content, hardening of temp folders.

## 1.4 — 2026-07

- Complete rewrite in PySide6; project open-sourced on GitHub under GPLv3.
- Dark/light theme, single-instance handling, faster update checks.

## 0.7 — 2024-04

- Fixed the "link too long" error and other minor bug fixes.

## 0.6 — 2023-06

- MP3 conversion.
- Added Dailymotion, Instagram and TikTok support.

## 0.5 — 2023-05

- Minor bug fixes.

## 0.4 — 2023-04

- Added support for downloading non-video files.

## 0.3 — 2023-03

- First public release with Pastylink integration.
