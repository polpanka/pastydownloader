# Security policy

## Supported versions

Only the latest release is supported. Before reporting a problem, please update
to the newest build from the
[Releases](https://github.com/polpanka/pastydownloader/releases/latest) page and
check whether it still occurs.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a vulnerability

Please report security issues privately, not in a public issue. Open a
[private security advisory](https://github.com/polpanka/pastydownloader/security/advisories/new)
on this repository.

Include the app version, your operating system, and the steps needed to
reproduce the problem. A proof of concept is welcome but not required.

You can expect an initial reply within a few days. If the report is accepted, a
fix will be shipped in a new release and you will be credited in the release
notes unless you prefer to stay anonymous.

## Privacy

PastyDownloader is designed to leave you alone. It has no accounts, no ads and
no user tracking. It does not build user profiles or record what you download.

The only data sent from the app is an anonymous check for a newer version, which
transmits nothing beyond the operating system and the app version. The links you
paste, the sites you visit and the files you save never leave your device.

Optional features that store data locally — such as reading your browser cookies
to download login-gated content — are off until you enable them, act only on
your machine, and can be turned off at any time.

## Third-party components

PastyDownloader bundles open-source components to perform downloads and media
conversion. These are updated with each release and can also be refreshed from
within the app. Vulnerabilities in those upstream projects should be reported to
their respective maintainers; if such an issue affects PastyDownloader users,
report it here as well so the bundled copy can be updated quickly.

## Open source

PastyDownloader is free and open-source software released under the GPLv3
license. Contributions and security reviews from the community are welcome.
