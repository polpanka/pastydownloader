PastyDownloader — это быстрое приложение без лишнего, чтобы забирать видео и аудио из интернета — та же философия «вставь ссылку», что стоит за [pasty.link](https://pasty.link), Multimedia Discovery Engine. Скопируйте ссылку — или целую пачку — нажмите «Вставить», а остальное приложение сделает само: выберет нужный движок, покажет прогресс и сохранит файл именно туда, куда вам нужно. Работает на Windows, macOS, Linux и Android из единой кодовой базы.

## ✨ Возможности

- 📋 **Вставляйте что угодно** — одну ссылку, десятки сразу или целый плейлист HLS (`#EXTM3U`), вставленный обычным текстом
- 🌐 **Сотни сайтов** — YouTube, Instagram, Facebook и сотни других, каждый направляется туда, где его лучше всего извлекут
- 📡 **Прямые потоки** — HLS/m3u8, DASH и прямые трансляции, скачиваемые прямо из источника
- 💬 **Автоматические субтитры** — скачиваются на языке приложения, когда доступны
- 🎵 **Извлечение звука в 5 форматах** — MP3, AAC/M4A, FLAC, WAV или Opus
- 🔒 **Контент с входом в аккаунт** — может использовать cookie вашего браузера, чтобы скачивать то, что требует учётной записи
- 🌍 **Говорит на вашем языке** — Deutsch, English, Español, Français, Italiano, Nederlands, Português, Русский, العربية, 日本語, 简体中文, 한국어
- 💻 **Кросс-платформенность** — Windows, macOS, Linux (с AppImage) и Android, всё из одной кодовой базы
- 🔗 **Дополнение к [pasty.link](https://pasty.link)** — тот же процесс «вставь ссылку», что и на сайте, на вашем компьютере и телефоне
- 🛡️ **Никакой возни** — без аккаунтов, без рекламы, без слежки, без ручной установки; одно бесплатное приложение, делающее одну задачу

## Требования

- **Windows** — Windows 10 (64-бит, 1809 или новее) или новее
- **macOS** — 11 (Big Sur) или новее (Apple Silicon и Intel)
- **Linux** — дистрибутив с glibc 2.28+ (например, Ubuntu 20.04+, Debian 11+, Fedora 29+, RHEL 8+)
- **Android** — 5.0 (Lollipop, API 21) или новее, arm64

## Почему PastyDownloader

Полностью безопасно: без вирусов, без рекламы, без слежки за пользователями. Без аккаунтов, без расширений браузера, борющихся за ваше внимание. Просто одно лёгкое бесплатное приложение, которое делает одну задачу — скачивание — и делает её хорошо.

## 📱 Сборка для Android

PastyDownloader начинался на десктопе, и сборка для Android — не отдельное приложение, а та же кодовая база [PySide6](https://www.qt.io/qt-for-python), скомпилированная под другую платформу. Настоящие загрузки yt-dlp выполняются на устройстве, включая реальное объединение аудио и видео через нативно скомпилированный FFmpeg, а не упрощённую замену.

Такое сочетание встречается редко: большинство приложений yt-dlp для Android — это нативные переписывания, не разделяющие код ни с одной десктопной версией, а Python-порты, повторно использующие существующий интерфейс, обычно построены не на Qt. Перенести полноценное приложение PySide6 на Android — доступ к хранилищу, мосты JNI, фоновая служба загрузки, нативный FFmpeg — потребовало длительной работы.

## 🙏 Благодарности

PastyDownloader стоит на плечах нескольких замечательных проектов с открытым исходным кодом. Огромное спасибо их сопровождающим и участникам:

- **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — движок извлечения, который разбирается в видеосайтах интернета, тихо работая за кулисами почти каждой загрузки.
- **[FFmpeg](https://ffmpeg.org)** — медиа-мощность, отвечающая за ремукс, преобразование форматов и кодирование MP3.
- **[Qt for Python (PySide6)](https://www.qt.io/qt-for-python)** — набор инструментов, лежащий в основе десктопного интерфейса.

Без этих проектов PastyDownloader просто не существовал бы.
